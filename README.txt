NIHARIKA'S PORTFOLIO

HOW TO PREVIEW
1. Extract this ZIP file.
2. Open the Niharika_Portfolio folder.
3. Double-click index.html to open the portfolio in your browser.

The website uses index.html, style.css, script.js, and bg.png.
Keep these four files together in the same folder.

This ZIP intentionally excludes the .git folder. It is a clean preview copy and does not change or push anything to GitHub.
